# Constructor and `this` Keyword in Java

This repository explains the concept of **Constructors**

## 📌 Constructor in Java

A constructor is a special method that is automatically called when an object is created.  
It is mainly used to initialize object variables.

### Key Points
- Constructor name must be the same as the class name
- It does not have a return type
- It is executed when an object is created
- Used to assign initial values

### Types of Constructors
- Default Constructor
- No-Argument Constructor
- Parameterized Constructor
- Copy Constructor
---

## 📌 `this` Keyword in Java

The `this` keyword refers to the current object of the class.

### Uses of `this` Keyword
- To differentiate instance variables from local variables
- To call another constructor of the same class
- To pass the current object as an argument
- To return the current class object
