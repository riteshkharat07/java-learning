# Polymorphism in Java

Polymorphism means **"one method, multiple forms."**  
It allows methods to perform different tasks based on the context.

## Types of Polymorphism

1. **Compile-time Polymorphism (Method Overloading)**  
   Same method name with different parameters in the same class.

2. **Runtime Polymorphism (Method Overriding)**  
   Child class provides its own implementation of a parent class method.

## Goal

Understanding polymorphism helps in writing flexible and scalable Java programs.
