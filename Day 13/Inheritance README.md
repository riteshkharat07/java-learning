# Inheritance in Java

This repository explains the concept of **Inheritance** in Java, one of the core pillars of Object-Oriented Programming (OOP).

## 📌 What is Inheritance?

Inheritance is a mechanism in Java where one class acquires the properties and methods of another class using the `extends` keyword.

It helps in:
- Code reusability
- Reducing duplication
- Creating a proper class hierarchy

---

## 🔹 Types of Inheritance in Java

1. Single Inheritance  
   One child class inherits from one parent class.

2. Multilevel Inheritance  
   A class inherits from a class which is already inherited from another class.

3. Hierarchical Inheritance  
   Multiple child classes inherit from a single parent class.

(Note: Java does not support multiple inheritance with classes, but it can be achieved using interfaces.)

---

## 🔹 Key Concepts
- Parent class (Super class)
- Child class (Sub class)
- `extends` keyword
- Method inheritance
- Method overriding
