# Collection Framework in Java

The Collection Framework in Java provides a set of classes and interfaces to store and manipulate groups of objects efficiently.

## 📌 Main Components

- List (ArrayList, LinkedList) – Ordered collection, allows duplicates
- Set (HashSet) – Does not allow duplicate elements
- Map (HashMap) – Stores data in key-value pairs

## 📌 Benefits

- Reduces programming effort
- Improves performance
- Provides ready-to-use data structures

## 🎯 Goal

Understanding the Collection Framework helps in writing efficient and scalable Java programs.
